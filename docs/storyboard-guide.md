# 古诗电影化分镜设计指南

分镜不是把诗句逐行配成插图。它要决定观众何时知道什么、看向哪里、听见什么，以及情绪如何发生变化。

## 1. 从诗的结构推导镜头

- **事件推进型：** 人物或事件发生变化，镜头需要清楚交代动作和因果。
- **空间探索型：** 观众跟随视线或移动逐渐认识环境，可用景别变化和空间关系建立体验。
- **情绪递进型：** 外部事件很少，依靠构图、距离、光线、声音和节奏推动。
- **瞬间定格型：** 力量集中在一个动作或意象，短片可以围绕这一瞬间展开。
- **跳跃或并置型：** 诗句之间可能是意象并列而非连续事件，应通过视觉关联建立联系，而不是强行补出故事。

一首诗可以同时具有多种结构。判断的目的是指导镜头，而不是给作品贴标签。

## 2. 镜头景别的叙事作用

| 景别 | 常见作用 | 注意事项 |
|---|---|---|
| 大全景 / 远景 | 建立空间、尺度、孤独感或人与环境的关系 | 主体可能很小，但仍需明确视觉焦点 |
| 全景 | 展示人物与环境的完整关系 | 适合表现行走、停留和空间调度 |
| 中景 | 观察人物动作、人与人之间的关系 | 不要让背景信息抢走动作重点 |
| 近景 | 捕捉反应、迟疑、观察和情绪变化 | 不要把每种情绪都拍成夸张表情 |
| 特写 | 强调关键物件、局部动作或感官细节 | 只在细节真正重要时使用 |
| 空镜 | 呈现空间、时间、缺席或余韵 | 空镜也要有变化或叙事作用，避免重复风景 |

景别不需要按固定顺序从远到近。镜头距离的变化应当对应观众与诗中世界关系的变化。

## 3. 摄影机运动

摄影机运动应当有理由。先问“观众为什么需要移动”，再决定如何移动。

- **固定镜头：** 让观众观察画面中的细微变化，适合等待、静观、缺席和留白。
- **缓慢推进：** 逐步强调某个细节或心理重心，推进的终点必须值得抵达。
- **后退 / 拉远：** 揭示环境规模、人与环境的比例，或让主体逐渐被空间吞没。
- **横移：** 揭示被遮挡的信息、跟随主体或建立空间层次。
- **跟拍：** 让观众与人物共享移动过程，要明确跟随方向和速度。
- **摇镜：** 把注意力从一个信息点转向另一个信息点，起点和终点都应有意义。
- **手持或不稳定运动：** 适合特定的主观感、紧张感或纪实感，不要为了“电影感”滥用。
- **航拍 / 大幅运动：** 只有当空间尺度、地形关系或叙事转折需要时才使用。

在 AI 视频提示词中，尽量一次指定一种主要摄影机运动，并将摄影机运动与主体动作分开写。

## 4. 构图与空间层次

描述构图时，不要只写“构图优美”。具体说明主体在画面的位置、前中后景关系、视线与运动方向、留白位置，以及主体和环境的比例如何表达情绪。

留白不是把画面做空，而是让观众感知未出现、未说出或无法抵达的东西。

## 5. 时间码与节奏

每个镜头都应有起止时间。镜头时长需要加总到目标时长附近，并为必要的停顿和转场预留空间。

- 不要默认每句诗对应同样长的镜头。
- 动作复杂时，给动作留出可理解的时间。
- 情绪转折前可以建立期待，转折后也可能需要停留。
- 慢镜头不是默认选项；静止画面也可以有很强的时间感。
- 如果多个镜头都在表达相同信息，考虑合并或删除。
- 影片结尾不必把诗意解释完。有时一个动作停止、一个声音消失或一个空镜就足够。

## 6. 光线、色彩与材质

避免只用“高级电影感”“氛围感”“唯美”作为指令。把它们转化为可以观察的选择：

- 光从哪里来：天空漫射光、侧逆光、窗光、火光或其他明确光源。
- 光是什么性质：柔和、硬朗、破碎、低角度或被遮挡。
- 色彩如何分配：主色、辅助色、对比色分别出现在哪里。
- 材质如何呈现：湿润岩石、粗糙树皮、薄纱、旧木、尘土或水面反光。
- 天气与时间是否连续：云层、雾、风向、太阳方向和地面湿度不能无缘无故变化。

色彩设计要服务于诗的意象与情绪，不应让所有作品都落入同一种青绿色调。

## 7. 声音设计

声音是叙事的一部分，不是配乐的装饰层。

1. **环境声：** 风、水、鸟、虫、远处的人声、空间混响等。
2. **动作声：** 脚步、衣料摩擦、树枝、器物碰撞等。
3. **音乐：** 决定是否需要音乐、何时进入、是否在关键镜头前退出。
4. **静默：** 可以是音乐停止，也可以是环境声被压低；不等于随意把音轨全部静音。

诗中出现声音时，判断它是可见声源、画外声源，还是一种记忆或心理感受。若无法在画面中明确声源，可以通过声音先于画面出现来建立期待。

## 8. 转场设计

转场应建立在动作、声音、构图或意义的关联上。

- **直接切：** 清晰、有力，不需要每次都用特效。
- **声音桥：** 下一个场景的声音提前进入，或上一个场景的声音延续到下一个场景。
- **动作匹配：** 通过方向、形状或动作相似性连接镜头。
- **构图匹配：** 用形状、位置或尺度相似的画面建立联系。
- **叠化：** 适用于时间流逝、记忆或空间融合，但不要泛用。
- **留白切换：** 在动作或声音停止后切到空画面，让缺席成为表达的一部分。

分镜表必须说明转场的意图。不要只写“电影级转场”。

## 9. AI 视频生成的连续性

逐镜生成容易造成角色、环境和摄影风格漂移。生成前建立一份连续性清单：

- **人物：** 年龄感、身形、发型、服装层次、鞋履、配饰、携带物。
- **环境：** 山路、溪流、竹林、建筑和地形之间的位置关系。
- **光线：** 太阳方向、时间、阴影方向、天气与空气状态。
- **动作：** 人物进入和离开画面的方向，动作开始与结束的状态。
- **视觉基准：** 写实程度、镜头质感、色彩逻辑和景深倾向。
- **道具：** 出现位置、持握方式及镜头间是否保留。
- **时间逻辑：** 如果场景从清晨推进到正午，必须有合理的时间过渡。

每条逐镜提示词应保留该镜头的必要约束，不要只依赖模型“记住前面的镜头”。

## 10. 文字与书法

如果诗句、片名或书法必须准确，建议在后期合成。许多视频模型生成文字时容易出现错字、变形或伪文字。

1. 生成干净画面，避免画面中出现不必要的文字。
2. 在剪辑或合成阶段加入经过校对的诗句。
3. 控制文字出现的时间、位置、字重和留白。
4. 不要让字幕遮挡关键主体，也不要用文字重复解释画面已经表达的内容。

## 11. 最终检查

- 每个镜头都有明确作用。
- 诗句与画面关系准确。
- 镜头时长总和合理。
- 运动描述可执行且不过载。
- 镜头之间有空间和视觉连续性。
- 声音有层次，关键位置有节制。
- 没有为了“古风”而堆叠不必要的符号。
- 结尾保留了作品自身的力量，而不是强行给出解释。
